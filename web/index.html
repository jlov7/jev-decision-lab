    Run a case first.

    A decision engine,
    not a smaller chatbot.

    Think of a dispatch desk. A writer can compose the response. Jev marks a structured decision sheet. Your software decides what is allowed to happen next.

    Choice

    Which listed team should investigate? You supply the choices and their descriptions. The model returns an option and the full probability distribution.

    operations: 0.62
    procurement: 0.33
    quality: 0.04
    other: 0.01

    The runner-up matters. Do not turn a narrow lead into false certainty.

    Score

    How consequential is the issue? Supply ordered, concrete descriptions. The returned score is a probability-weighted level index.

    P(limited) = 0.50
    P(critical) = 0.50

    A mean can hide a dangerous tail. Inspect the distribution, not just a single number.

    Noul

    Is there enough evidence? The answer is a number between zero and one representing the model’s probability of “yes.”

    P(evidence sufficient) = 0.45

    0.5 is uncertainty between yes and no. It is not “medium severity.” Noul has no separate confidence field.

    The important boundaries

    Valid shape is not factual correctness. A returned probability is not automatically calibrated for your domain. Independent questions do not imply independent errors. A classifier cannot grant permissions, create missing evidence, or make an outdated source current.

    A useful system has three kinds of work

    Code checks identity, dates, amounts, permissions and policy. Jev supplies bounded semantic judgments. A reasoning or writing model investigates difficult exceptions or drafts a response, only when needed. A human approves consequential decisions.

    Try these three teaching moments

    Open “The word delay is not a delay” to distinguish meaning from a keyword. Then expire its evidence and replay the policy. Finally run “Confident, but assigned to the wrong team” and open Evaluation. A more confident answer can still be the wrong one.

    From account to first call

    Open the TypeSafe console, try a state and three question types in Playground, then create an API key in the dashboard. Check your account’s credits, model access and limits there.

    In the same terminal that starts the app, on macOS:

    read -s TYPESAFE_API_KEY
export TYPESAFE_API_KEY
export JEV_ALLOW_LIVE=1
export JEV_MODEL=jev-1.13.0
python -m jev_lab

    The first command waits for your key without echoing it. This app does not read a .env file. Restart the server, choose Live TypeSafe API, check the consent box and run one case.

    No key belongs in source control, a browser, a screenshot or a prompt. Only the synthetic cases bundled with this lab can be sent from this UI. Live mode makes no automatic retries and stops at a session request cap.
