# Review and recovery design · 20 September 2026

## Intended outcome
A local, independent teaching and experiment lab for engineers, leaders, domain owners and risk reviewers. Preserve the original synthetic cases and provider boundaries. Make the first five minutes understandable; expose useful, falsifiable judgment patterns without pretending that more features prove Jev's value.

## Work packages
1. Measurement integrity: preserve failed-call billing, refuse mixed-version evaluation, distinguish incomplete probes from stable results, compare ablation probabilities on the same label, and distinguish input sensitivity from causation.
2. User journey: Start screen and a key-free lesson; eight versioned Decision Studio patterns with explicit request previews, adverse examples, and study-design export. No generated probabilities for new patterns.
3. Workflow economics: editable assumptions, all-attempt model cost, failure review, imperfect review, error loss, capacity and sensitivity. No measured ROI or authorization.
4. QA and publication: current research register, frozen ten-category rubric, Python/JavaScript/browser tests, and branch/PR read-back. Preserve historical evidence. No automatic merge, deployment or publicity.

## Acceptance boundaries
Browser results must say whether navigation/CSP was tested or a bridge was used. No independent-panel claim without independent reviewers. No 90+ score earned merely by adding tests or rewriting the rubric. Missing external validation remains an explicit release gate, not an invented result.

## Recovery
