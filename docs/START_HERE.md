# Start here · Jev Decision Lab 0.6

The lab asks a practical question: can a bounded semantic judgment improve a workflow once evidence, review and authority are counted?

Run `uv run jev-lab` from the cloned repository and open http://127.0.0.1:8765. No account or key is needed for the first lesson. Nothing is sent to a provider on startup.

## First five minutes

Choose **Start the three-step lesson**. Inspect an authored answer, withdraw approval and expire evidence, then see a deliberately confident wrong fixture. Complete the three-question teach-back and export the learning record. None of those outputs is measured Jev behavior.

Remember the four separate objects: **the model's opinion; the evidence available; the policy decision made in code; the permission to act**. A valid output shape is not proof of a correct answer, and neither grants authority.

## Next fifteen minutes

Open **Decision Studio**. Select a pattern relevant to the work, switch from routine to adverse, read the source and typed questions, and inspect the code boundary and strongest baseline. Export the request or an `UNRUN` study design. The examples do not carry invented model results.

Use the economics worksheet to change failure rate, review time, error loss and available review hours. All numbers are assumptions; the calculation is not a business result. A positive difference with a review-capacity shortfall is not a feasible scenario.

## With an approved personal research key

Connect Jev locally, then explicitly authorize one displayed synthetic Studio request. Inspect the result or retained failure and export it. No automatic retry or replay fallback exists. Use the Live lab for repeated-call variation, evidence ablation and comparisons; read failed-attempt counts and cost unknowns before interpreting the successful subset.

Do not use company or client data. No real action is possible in the local authority simulation. A new key, account, receipt or green test does not create enterprise approval.

Read [STUDIO.md](STUDIO.md), [EVALUATION.md](EVALUATION.md), [QA.md](QA.md) and [the review rubric](review/RUBRIC.md) before making a stronger claim. The original owner-recorded September 18 observations remain in `evidence/`; v0.6 adds engineering and teaching capabilities, not a new measured Jev performance claim.
